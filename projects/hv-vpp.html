HV‑VPP Resin Printer

A scratch-built vat photopolymerization (resin) 3D printer, with a PLC-controlled UV/LCD masking system driving the cure and a precision Z-axis and leveling setup underneath it.

Process
Vat Photopolymerization
Controls
PLC

What it does: the printer cures a photopolymer resin layer by layer using a masked UV light source, projected through an LCD panel that acts as a dynamic mask for each slice. A PLC handles the timing and sequencing between the UV exposure, the LCD mask, and Z-axis motion.

Getting it reliable

Getting reliable prints meant tramming the build plate so it's parallel to the resin vat within a tight tolerance, tuning the Z-axis motion so layers separate cleanly from the FEP film, and validating the roller and recoating system so resin flows back in evenly between layers.
